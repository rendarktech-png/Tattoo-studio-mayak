# МАЯК — тестовый сайт тату-коллектива

Отдельный локальный проект на React, TypeScript и Vite. Публикация не настроена.

## Запуск

```bash
npm ci
npm run dev
```

Проверка сборки: `npm run build`.

## Фотографии

Все пути собраны в `src/media.ts`. Добавьте файлы точно с этими именами:

| Место | Файлы | Рекомендуемые пропорции |
| --- | --- | --- |
| Главный экран | `public/images/hero/hero-01.webp`, `hero-02.webp` | 3:4, вертикальные |
| Портфолио | `public/images/works/work-01.webp` … `work-12.webp` | 3:4, вертикальные |
| Интерьер | `public/images/studio/studio-01.webp`, `studio-02.webp` | 1:1, квадратные |

Пока файлов нет, видны чистые чёрные блоки. После добавления файлов и обновления страницы фотографии появятся автоматически. В галерее доступны только добавленные работы; при увеличении изображение показывается целиком с исходными пропорциями.

Для портфолио добавляйте **цветные** файлы. Сайт показывает плитки чёрно-белыми через CSS, а при наведении возвращает цвет и слегка увеличивает изображение. В увеличенном просмотре фотография остаётся цветной. Отдельные чёрно-белые версии файлов не нужны.

При будущей публикации в подпапке передайте Vite соответствующий базовый путь, например `npm run build -- --base=/имя-проекта/`. Манифест фотографий уже учитывает `BASE_URL`.
